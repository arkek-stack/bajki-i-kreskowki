# Bajki i kreskówki – praktyczny angielski

Landing page kursu wideo dla dzieci 7–14 lat (poziom A1–A2). Czysty HTML + CSS + vanilla JS, bez kroku budowania.

## Podgląd lokalny

```
python -m http.server 8123
```

Następnie otwórz http://localhost:8123.
